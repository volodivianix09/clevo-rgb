# Changelog

## 1.0.0 — 2026-11-06

First public release.

- Native control of a single-zone Clevo keyboard backlight through `InsydeDCHU.dll`
- Seven modes: Off, Static, Breathing, Rainbow, Pulse, Blink, Color sequence
- 24-color palette and custom RGB / HEX color picker
- Multi-color sequence editor with breathing or cross-fade
- Brightness and speed controls
- Live apply and automatic saving
- Tray icon, single-instance behavior and autostart
- Russian UI, no administrator rights, no telemetry
- Loads the vendor DLL from the local folder or from Control Center 3.0
