# DCHU single-zone protocol

This is an unofficial note about the protocol used by Clevo RGB. It was
observed on a THUNDEROBOT 911 Plus (Clevo NH79HX-H) with Control Center 3.0.
It is not documentation from Clevo or Insyde. The protocol may differ on other
models.

## Export

The vendor DLL exports:

```c
int SetDCHU_Data(int command, byte[] buffer, int length);
```

`command` is `0x67` (`103`). The buffer is 4 bytes, little-endian. The call
returns `103` on success.

## Payload layout

The 32-bit argument is built as:

```text
args = (commandByte << 24) | (B << 16) | (R << 8) | G
commandByte = 0xF0 | slot
```

| Bits | Meaning |
|---|---|
| 31..28 | `0xF` |
| 27..24 | slot (`0`, `1` or `2`) |
| 23..16 | blue |
| 15..8 | red |
| 7..0 | green |

Note the unusual color order: **B, R, G**, not RGB.

## Color write sequence

Set a color by writing three slots in order:

```text
slot 0 -> args = 0xF0 | (B << 16) | (R << 8) | G
slot 1 -> args = 0xF1 | (B << 16) | (R << 8) | G
slot 2 -> args = 0xF2 | (B << 16) | (R << 8) | G
```

The last write (slot 2) switches the controller to static-color mode. Writing
only slots 0 and 1 does not reliably show the new color.

Examples:

| Color | Slot 0 | Slot 1 | Slot 2 |
|---|---|---|---|
| Red `#FF0000` | `0xF000FF00` | `0xF100FF00` | `0xF200FF00` |
| White `#FFFFFF` | `0xF0FFFFFF` | `0xF1FFFFFF` | `0xF2FFFFFF` |
| `#123456` | `0xF0561234` | `0xF1561234` | `0xF2561234` |

## Animation

The controller is single-zone and accepts one static color at a time. Smooth
effects are generated by the application: it writes a new color about 25 times
per second (every 40 ms). This is enough for a convincing breathing, rainbow or
pulse effect, but it is not a hardware animation engine.

Brightness is implemented by scaling the RGB values before sending them.
Clevo RGB does not use a separate hardware brightness command.

## Limitations

- One zone only: every key has the same color and brightness.
- No per-key addressing.
- No 3-zone or lightbar commands.
- The controller may ignore writes while the vendor utility is in a special
  mode or after an Fn hotkey changes the lighting mode.
- The vendor DLL is proprietary and is **not** included in this repository.
